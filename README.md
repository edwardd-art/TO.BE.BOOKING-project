# TO.BE.BOOKING — Система бронирования столиков

## Описание проекта
Веб-приложение для бронирования столиков в ресторане-баре "TO.BE.BAR".
Разработано в рамках дипломной работы.

## Функционал
- 🏠 Главная страница с описанием и обратной связью
- 📅 Интерактивная схема зала для бронирования
- 👤 Личный кабинет с историей и управлением бронированиями
- 🔐 Авторизация и регистрация
- 📱 Адаптивный дизайн на Bootstrap
- 🐳 Docker-контейнеризация

## Технологии
- Django 5.2
- PostgreSQL 15
- Bootstrap 5
- Poetry
- Docker & Docker Compose

## Установка и запуск

### Локально (без Docker)
```bash
poetry install
poetry run python manage.py migrate
poetry run python manage.py createsuperuser
poetry run python manage.py runserver

### Через Docker
bash
docker-compose up --build
